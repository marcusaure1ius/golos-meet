## Объём

Вторая из трёх частей UI #37 — ручные исправления и отмена утверждений с сохранением истории:

- `ProjectMemoryPanelModel`: `prepareCorrection` (lease через принятый `ProjectMemoryHistoryService.beginCorrection`, валидация draft'а `MemorySQL.validate`, stamp-fence + `validateMemoryLease` до показа превью, watched-источники lease) и `publishCorrection` (повторная проверка stamp перед записью → `journal.publish` → `worker.changed()` → reload); `MemoryCorrectionPreview` (CAS-превью); `cancelAction`.
- `ProjectMemoryPanel`: редактор ручного исправления/отмены (текст, гражданские дни сроков для deadline, дата решения), проверенное превью «только на этом Mac» с предупреждением о повторной проверке перед записью, кнопки «Изменить»/«Отменить факт» на карточках событий и «Исправить/Отменить утверждение» в провенансе (закрывает P3 №1 координационного ревью: текст «его можно явно отменить или исправить» теперь обеспечен действиями).
- Гарантии: исходное событие не затирается (append-only журнал, триггеры UPDATE/DELETE запрещены), ручная отмена не перезаписывается автоматикой (retraction ручного события моделью запрещён в принятом extractor/SQL), конкурентная публикация между превью и применением отклоняется как stale, даты — канонические гражданские дни UTC (импорт-дата не подставляется как дата решения).

Согласие/отправка и действия очереди — следующая часть (#37 не закрывается).
