# Предварительный протокол #28

Зафиксирован до просмотра результатов эмбеддингов на этом наборе. Корпус:
48 русских синтетических фрагментов, 6 вымышленных проектов, 20 вопросов.
Обычный вопрос имеет 2 релевантных фрагмента, два межпроектных — по 4.
Разметка, тексты и порядок не меняются после расчёта. Все фрагменты участвуют
в каждом поиске; проект/дата не являются фильтром или входом модели.
SHA-256 corpus.json: `1e1173bfa57d645539117f3752ba54b00c82670980c88b5026a42aa764eeb5a0`.

Кандидаты: пользовательская intfloat/multilingual-e5-small (revision из
приложения fd1525a9fd15316a2d503bf26ab031a61d056e98) и отдельная
sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2 (revision
 e8f8c211226b894fcb81acc59f3b34ba3efd5f42). Это исследовательский выбор;
рабочая модель приложения автоматически не меняется.

Оба используют официальные float32 ONNX, batch=1, CPU, 2 intra-op потока,
отключённое idle spinning, последовательную подачу входов. Среднее по токенам
с attention mask, затем L2 и cosine; E5 получает query:/passage:, MiniLM —
исходный текст. Лимиты — 512 и 128 токенов, соответственно; длинный вход
отклоняется, скрытого усечения нет. Набор задуман короче обоих лимитов.

Три отдельных последовательных процесса на кандидата, порядок чередуется
E5/MiniLM, MiniLM/E5, E5/MiniLM. В каждом процессе отдельно измеряются проверка
файлов, init (локальный токенизатор + ORT session), один первый запрос, затем
индексация всех фрагментов. После этого по 10 раундов всех 20 запросов в
фиксированном порядке. Время запросов — только токенизация/inference/pooling,
без cosine-поиска и JSON. Индексация измеряется wall-time той же native embed
операции; хеширование файлов не входит в init/index/query.

Память — ru_maxrss отдельного CLI-процесса (байты на macOS), включая runtime,
токенизатор, индекс и сериализацию отчёта. Нельзя называть init холодным чтением
с диска: кеш ОС не сбрасывается. Одновременные чужие нагрузки не контролируются.

Метрики по каждому запуску: top1 = доля вопросов с релевантным первым
результатом; recall@5 = среднее |top5 ∩ relevant| / |relevant| по вопросам.
Отдельно сохраняются числители/знаменатели и полный ranking. Равные cosine
разрешаются стабильным id. Публикуются исходные задержки, median/p95 по каждому
процессу, init, docs/s, tokens/s, peak RSS и размер необходимых файлов.
Сводка использует медианы process-level метрик и диапазон трёх процессов,
не усредняет перцентили в общий p95. Проверка метрик независимо пересчитывается
Python по rankings; inference исполняется только Swift/ORT, без Python ML.

После подготовки публичных файлов все native процессы запускаются под
sandbox-exec с `(deny network*)`. Не запускаются app, ASR, рабочая библиотека,
пользовательские файлы или облачный inference. Веса и кеш — только /tmp.
Набор маленький, написан одним автором и имеет близкие пары; он не представляет
архив или 2–3 реальных проекта. Различия в нём не доказывают общее превосходство
модели, причинность или необходимость менять пользовательский выбор.
