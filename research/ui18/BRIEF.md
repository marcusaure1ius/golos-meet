# Рабочая область Golos Meet — варианты для выбора

Статус: **макеты, не согласованы, не production**. 31 октября 2026. Refs #18.

## Задача и направление

Режим Impeccable — Operate. Пользователь возвращается в проект, проверяет, что изменилось после встречи, читает первоисточник, задаёт вопрос и связывает договорённость с задачей Constance. Широкое окно и fullscreen — основные композиции. Native macOS, Liquid Glass и ориентир Codex уже заданы пользователем; спор между проектом и чатом не решён.

Известный контекст перенесён в PRODUCT.md без повторного интервью. Неустановленные роли и частота сценариев оставлены открытыми. Установленный Impeccable не имеет отдельного macOS playbook: применены его Operate/new-work/craft-floor и официальные HIG/AppKit, без подмены на iOS, веб-детектора или обновления навыка. Доступна новая версия Impeccable 4.6.0; текущая работа использует установленную 4.2.2.

Ранние native макеты являются артефактом выбора, поэтому не утверждают DESIGN.md как новую production-систему. Код макетов строится отдельно от приложения. Вместо локального сервера выбора результат передаётся координатору файлами по прямому поручению; выбор и согласование ещё впереди.

## Рассмотренные структуры

| Структура | Применимость и риск |
|---|---|
| A. Проектный кабинет | Обзор, материалы и память доступны без формулирования вопроса. Чат справа; требует дисциплины панелей. |
| Читальный стол | Два источника рядом; полезен для сверки, но слабее для ежедневного обзора. Возможный режим выбранной структуры. |
| Хронология проекта | Объясняет изменения решений, но документы без даты теряются. Возможный режим памяти. |
| B. Диалог и материалы | Вопрос в центре, справа источники/задача. Лучше для синтеза, хуже для обзора без запроса. |
| Редактор документа | Уместен при чтении; превращает другие сценарии в исключения. |
| Задачный список | Силен для исполнения, но дублирует смысл Constance и прячет знания. |
| Пульт встречи | Силен во время записи, не покрывает работу между встречами. |

Impeccable concept-seed выполнен, seed 03930534, назначенная структура №4 — B. Она представлена полностью, A — самостоятельная сравнимая альтернатива и предварительная рекомендация. Это порядок исследования, не выбор пользователя. Шесть внешних метафор рассмотрены как контрпроверка, все отклонены по узнаваемости нативной рабочей области и ясности задачи: билетная книжка навязывает линейность, Metro прячет плотные материалы, музыкальный каталог кодирует смысл, аэропорт навязывает маршрут, стриминговая стена скрывает метаданные, фотолаборатория усложняет слои. Сохранены дисциплины: явные завершённые/отменённые состояния (билет), строгая иерархия (Metro), устойчивые ID (каталог), явный следующий шаг (навигация), доступность клавиатурного фокуса (стриминг), конфликт как отдельное состояние (фотолаборатория). Их стилистика не переносится вопреки заданному native направлению.

## Одинаковый синтетический сценарий

Проект «Север / Клиентский портал», соседний «Мобильный кабинет», Входящие. Встреча «Готовность пилота» 30 октября, 42 мин; документ «Условия пилота.pdf», версия 3, страница 7. Решение: пилот 12 ноября, только чтение; экспорт требует проверки безопасности. Встреча и документ расходятся в трактовке экспорта. Задача DEMO-142 «Проверить экспорт» с двумя подзадачами. Эти данные вымышлены. Счётчики описывают этот макет, а не рабочую библиотеку.

## A — проект в центре

Слева дерево проектов, внутри проекта Обзор/Встречи/Документы/Память/Задачи, не более двух уровней. В центре выбранный материал или обзор с изменениями, решениями и открытыми вопросами. Справа контекстный чат и его область источников. Ответная ссылка открывает источник в центре и сохраняет диалог. Поиск временно занимает центр; возвращение восстанавливает материал и прокрутку. Чат закрывается отдельно.

В 1440×900: sidebar 236, чат 340, остальное материал. В fullscreen 1920×1080 дополнительное место достаётся материалу и полям вокруг текста, а не размеру букв. Мера прозы ограничена примерно 70 знаками, таблицы используют ширину. Не открывать четвёртую постоянную колонку.

## B — чат в центре

Слева проекты и история диалогов. В центре вопрос/ответ со ссылками и явным scope; справа рабочая панель с вкладками Материалы/Память/Задачи. Выбор источника показывает страницу/расшифровку в этой панели, диалог не исчезает. Поиск остаётся локальным и открывает список результатов, а не запускает LLM автоматически. Обзор проекта доступен из панели, но уступает диалогу место.

В 1440×900: sidebar 236, чат около 520, материал — остаток. В fullscreen чат до 650, остальное источник; ширина ответа ограничена. Панель можно развернуть для чтения, временно скрыв чат, и вернуть с сохранением черновика. Это переключение композиции, не новый экземпляр источника.

## Общие правила поведения

| Область | Контракт будущей реализации |
|---|---|
| Размеры | Рабочие размеры 1440×900 и 1920×1080. Сохранить поддержку окна 1000×680: сначала убрать инспектор, затем свернуть sidebar; навигация доступна кнопкой/меню. Split divider перетаскивается, размеры сохраняются на проект. Текущие макеты показывают два основных размера, узкий режим ещё не реализован. |
| Панели | Sidebar 220–300; чат 340–650; читаемый материал от 420. Если сумма минимумов не помещается, переключить композицию, не обрезать. Один preview slot для цитаты, закрепление открывает вкладку, Back возвращает прежний материал. |
| Поиск | Глобальная команда ⌘K; видимый scope «Все проекты»/текущий проект; поиск строк/фрагментов локально. Результат содержит тип, проект, версию/дату и страницу/таймкод. Ошибка индекса не выглядит как 0 результатов. |
| Облако | Scope и разрешение проекта рядом с composer. Отдельный облачный запрос запускается только явным действием. Смена проекта не переносит скрытый контекст. Shared source учитывает политики всех владельцев. |
| Память | Решение, источник и дата раздельно; конфликт показывается вместе с обеими версиями. Ручное исправление сохраняет историю, а не переписывает цитату. |
| Constance | Один список внешних задач с ID, состоянием/временем синхронизации и ссылкой на источник. Редактор открывается рядом, подзадачи вложены. Сохранение, ошибка, повтор, потеря связи видны. Нет optimistic «готово» до подтверждения. Поля и поддержка операций уточняются #6. |
| Запись | Постоянный короткий статус в верхней панели плюс menu bar независимо от проекта. Текст «Запись 18:42 · 2 дорожки», «Нет сигнала», «Толк недоступен»; mute/тишина не означает поломку. Во fullscreen доступен статус в окне. Потеря дорожки — баннер и путь к диагностике. Не заявлять живую ASR. |
| Клавиатура | ⌘K — поиск, ⌘F — внутри материала, ⌘, — настройки, ⌃⌘F — системный fullscreen. Предлагаемые ⌥⌘S / ⌥⌘I — sidebar/инспектор, требуют проверки конфликтов. Tab/Shift-Tab внутри панели; системная навигация между областями; Escape закрывает временную панель и возвращает фокус инициатору. Enter открывает результат; для отправки вопроса предлагается ⌘Enter, Enter — перенос. |
| VoiceOver | Панели имеют имена «Проекты», «Материал», «Диалог». У кнопки цитаты — имя источника и страница/время. Выбор материала объявляет заголовок, не весь документ; запись объявляет смену состояния, не каждую секунду. После ошибки фокус на сообщении с действием восстановления. |
| Темы | Семантические NSColor/SwiftUI system colors, SF и SF Symbols. Акцент следует системному. Длинные заголовки переносятся, строки дерева обрезаются с help/accessibility полным названием. Выбор не различается одним цветом. |
| Материалы | Стандартные sidebar/toolbar/inspector получают системный вид. Пользовательский glass — только ограниченные группы навигации/записи на macOS 26+. Проза, PDF, поиск, транскрипт и текст ответа непрозрачны. Не добавлять стекло на каждую строку. |
| Reduce Transparency | Непрозрачные sidebar/toolbar, те же границы и контраст. Reduce Motion — отсутствие spatial morph/slide; короткая смена/без анимации. Состояние и завершение операции читаются без движения. |
| Производительность | Виртуализированные списки, async чтение/поиск, отмена устаревших запросов. Не пересобирать расшифровку на tick таймера записи. Показатели startup/scroll/resize надо измерить в реализации, статичные PNG их не доказывают. |

## Состояния

У каждой области есть основное, пустое, loading и error состояние. Галерея показывает: пустой проект с импортом/назначением встречи; загрузку/отмену индекса; ошибку индекса с повтором; запрет облака с понятным scope; конфликт памяти с двумя источниками; Constance offline с сохранённым черновиком и временем последней синхронизации. Запись отдельно показывает здоровье двух дорожек и ошибку. Настройки — отдельное системное окно с разделами Общие, Запись, Модели и индекс, Подключения, Разрешения проектов; секреты маскируются и не попадают в макеты.

Матрица ниже — контракт следующего интерактивного прототипа. Галерея иллюстрирует общие паттерны, а не все комбинации каждой области.

| Область | Пусто / покой | Загрузка | Ошибка и восстановление |
|---|---|---|---|
| Запись | «Запись не идёт», явный ручной старт | «Готовим дорожки», не показывать успешную запись раньше готовности | Какая дорожка недоступна, что продолжает сохраняться, диагностика/повтор |
| Проект | Добавить документ / назначить встречу | Сохранить дерево и выбранный проект, загрузить содержимое | Не скрывать дерево; показать ошибку хранилища и повтор |
| Встреча | Расшифровки ещё нет, аудио сохранено | Очередь/расшифровка с отменой по контракту pipeline | Ошибка ASR отдельно от записи, повтор без удаления оригинала |
| Документ | Текст не извлечён, оригинал доступен | Прогресс импорта/индекса с отменой | Защищён/повреждён/неподдерживаем; выбор файла/повтор |
| Поиск | «Ничего не найдено» только после успешного запроса | Сохранить запрос и scope, отменять устаревший поиск | «Индекс недоступен», не 0 результатов, повтор/настройки индекса |
| Вопрос | Предложение задать вопрос по выбранным материалам | «Ищем контекст» / «Готовим ответ» раздельно, stop | Запрет политики/нет контекста/transport error различаются; черновик сохраняется |
| Память | Решений пока нет, предложить материал | Последняя версия остаётся видна с датой обновления | Не удалось обновить / конфликт: обе версии и источники, ручное уточнение |
| Constance | Нет связанных задач; предложить связать/создать по явному действию | Синхронизация/сохранение; не подтверждать отправку раньше ответа | Offline/нет прав/конфликт версии; сохранять черновик, повтор после исправления |

## Выбор, который нужен пользователю

1. Какое постоянное ядро удобнее: A — проект/материал, B — диалог? Можно выбрать B и сохранить полноэкранное чтение источника.
2. Держать ли чат/материалы открытыми по умолчанию или открывать по запросу с запоминанием выбора?
3. Достаточно ли списка задач + редактора рядом, или ежедневной работе нужна закрепляемая панель задач во время встречи?

Предварительная рекомендация — A: она делает встречу, документ и память доступными до запроса и даёт место проверке источника. B предпочтительнее при основном ритуале «задать вопрос и действовать по ответу». Никакой вариант пока не принят. Минимальную ОС предлагается сохранить 14.4 с availability fallback; менять её ради эффекта не требуется.
