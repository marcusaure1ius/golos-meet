# Нативная локальная модель: первая часть #13

Реализованы нативный encoder E5, управление установкой и карточка в настройках.
Это первая проверяемая часть #13. Хранение векторов документов/встреч, очередь
индексации, переиндексация, сравнение моделей и подключение поиска к библиотеке
остаются в следующих PR; родительская задача сохраняет все критерии.

## Закреплённый комплект

- ONNX Runtime SwiftPM 1.24.2, официальный пакет Microsoft, CPU, два потока,
  отключён idle spinning. Runtime входит в сборку приложения.
- Swift Transformers 1.3.5, локальная загрузка Unigram/XLM-R токенизатора.
  `Package.resolved` фиксирует также транзитивные зависимости.
- `intfloat/multilingual-e5-small`, revision
  `fd1525a9fd15316a2d503bf26ab031a61d056e98`, float32 ONNX, 384 измерения.
- Пять файлов, 487 352 505 байт. Пути, размеры, SHA-256 и адреса находятся в
  `EmbeddingModelManifest.swift`. Контрольная сумма обязательна для каждого файла,
  включая конфигурацию. Размер прежнего Python-прогона отличается на три небольших
  файла конфигурации.

Префиксы `query: ` и `passage: ` применяются для всех языков. Предел — 512 токенов
включая префикс и специальные токены. Запрос сверх предела отклоняется явно.
`passageWindows` делит длинный материал по токенам с перекрытием 64, сохраняет
смещения и последнюю часть. Каждый сегмент получает отдельный вектор; усреднения
целого длинного документа нет. Внутри сегмента применяется mean pooling по
attention mask, затем L2. Batch size — один, padding отсутствует. Идентификатор
вектора включает revision и версию конфигурации; несовместимые модели/размерности
отклоняются существующим `KnowledgeVector`.

У upstream Unigram свойство `bosTokenId` описывает пробел и возвращает nil для
этого комплекта. Поэтому проверяются фактические ID `<s>`=0, `</s>`=2, `<pad>`=1
и результат шаблона токенизации, а не необязательное свойство.

## Установка

Пользователь выбирает явную загрузку публичных файлов с Hugging Face или папку
с тем же закреплённым комплектом (`onnx/model.onnx` и четыре JSON в корне).
Внешняя папка копируется в управляемое хранилище; оригинал не изменяется и после
установки не требуется. Символические ссылки и файлы другой версии отклоняются.
Установка идёт во временный каталог. После SHA-256 выполняется настоящий нативный
расчёт на фиксированном синтетическом тексте; только затем атомарно обновляется
`embedding-models/active.json`. Ошибка/отмена не заменяют прежний указатель.
При повторном открытии настроек снова проверяются целостность и работа модели.

Старые активированные каталоги сохраняются для незавершённых читателей. В первой
части нет автоматической сборки мусора: каждая успешная повторная установка может
занять ещё 488 МБ. Временная установка удаляется при штатной ошибке/отмене;
после аварийного завершения процесса её каталог пока может остаться на диске.
Содержимое документов и встреч в сетевой транспорт не передаётся. Encoder
использует исключительно `AutoTokenizer.from(modelFolder:)` и локальный ONNX.
`from(pretrained:)` и удалённый inference отсутствуют.

## Проверки и воспроизведение

`make check` проверяет синтетические файлы: независимость управляемой копии,
подмену байта при том же размере, отсутствующий файл, символическую ссылку,
ошибку runtime, настоящую отмену выполняющегося Task и сохранность прежней активации.
Весов в git и неявного скачивания в обычных тестах нет.

Для настоящей модели явно укажите подготовленный комплект:

```sh
TEST_RUNNER_GOLOS_MEET_E5_FOLDER=/path/to/pinned-e5-small \
TEST_RUNNER_GOLOS_MEET_E5_REPORT=/tmp/native-e5-results.json make check
```

`E5NativeTests` сверяет точные токены трёх синтетических русских/Unicode строк и
первые 16 компонент их векторов с независимым эталоном tokenizers 0.23.3 /
ONNX Runtime 1.31.1 (допуск 1e-4). Python здесь создавал только эталон;
приложение и gated-тест вычисляют векторы нативно. Проверены отказ для длинного
запроса, покрытие хвоста, перекрытие и совпадение короткого окна с обычным passage.

Результат `native-e5-small-2026-10-30.json`: Apple Silicon, macOS 27.0.1,
Debug XCTest, 10 синтетических фрагментов / 8 вопросов из прежнего эксперимента.
Top-1 — 7/8, recall@5 — 8/8; первичная инициализация 1,64 с, расчёт десяти
фрагментов 56 мс, запросы 3,84–4,77 мс. Пик RSS всего процесса — 1 389 150 208
байт; параллельно шли другие тесты. Дисковый кеш ОС не сбрасывался. Набор мал,
не представляет рабочий архив и не доказывает превосходство над другими моделями.

Отдельный нативный CLI позволяет запретить сеть на уровне процесса без запуска
приложения, записи, Keychain или библиотеки:

```sh
make build
python3 research/build_native_embedding_probe.py
sandbox-exec -p '(version 1)(allow default)(deny network*)' \
  /tmp/golos-native-embedding-probe /path/to/pinned-e5-small /tmp/offline-e5.json
```

Python в этой команде вызывает компилятор и не исполняет модель. Воспроизведено
30 октября: полный SHA-256 комплект проверен, native probe вернул 384 измерения
с запрещённой сетью; инициализация 1,30 с, запрос 4,56 мс, пик RSS 1 365 245 952
байт. Это smoke-проверка локальности, не сравнение моделей.

Живой UI проверен в отдельном временном host без AppDelegate, записи и рабочих
данных: исходное состояние, реальная загрузка/отмена/повтор, ошибка неполной
папки, успешная установка из выбранной папки, полный download и native probe.
